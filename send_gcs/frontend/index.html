AI Processing Pipeline
1
Receive
Ingests raw RTSP stream frames from the UAV camera via MediaMTX. Validates frame integrity and buffers incoming data.
2
Decode
Decodes compressed video frames (H.264/H.265) into raw image data. Applies preprocessing such as resizing and normalization.
3
AI Inference
Runs the selected AI model against each decoded frame. Generates embeddings and detects targets matching the mission prompt.
4
Compare
Compares AI inference results against the mission target prompt using cosine similarity. Applies confidence threshold filtering.
5
Save
Saves confirmed detections (bounding box, confidence, frame snapshot) to backend storage for post-mission analysis.
6
Publish
Broadcasts detection events to the GCS dashboard in real time. Updates mission statistics and triggers operator notifications.
